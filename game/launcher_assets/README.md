# Launcher art

Optional images for the pre-boot launcher, generated by
[`../tools/launcher-art.sh`](../tools/launcher-art.sh):

| File | Where it appears |
|---|---|
| `boxart.tga` | the big GAME card on the dashboard |
| `brand_mark.tga` | the small mark next to the title, top-left |
| `pad.tga` | the controller image on the Controller page |

The launcher loads them from `assets/img/` beside the executable; the CMake
build copies them there when they exist. Without them recomp-ui draws its
default cartridge, brand mark and SNES pad.

`launcher-art.sh` turns a PNG/JPG into the 32-bit TGA these slots expect and
rebuilds the game. Commit the TGAs you want in a release: the setup packager
copies tracked files only.

```sh
game/tools/launcher-art.sh --boxart my-cover.png --key-black --trim
game/tools/launcher-art.sh --brand my-mark.png --key-black --trim
game/tools/launcher-art.sh --clear
```
