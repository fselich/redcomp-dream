# Chat filter word list -- shared by the C filter (lib/recomp-net, every
# client, LAN included) and the lobby server (recomp-net-server). The server
# keeps a copy at data/chat_filter_words.txt; keep the two identical.
#
# One entry per line. '#' starts a comment. Matching is done on FOLDED text:
# lower case, Latin diacritics stripped (é -> e, ß -> s), full-width ASCII
# narrowed, and leetspeak undone (0->o 1->i 3->e 4->a 5->s 7->t @->a $->s
# !->i |->l +->t). Write entries in that folded form. Repeated letters
# ("fuuuck") and separators between letters ("f.u.c.k", "f u c k") in words
# of four or more letters are matched automatically; a phrase is written
# without its spaces ("filhodaputa") for the same reason.
#
# Default: whole-word match (letters on either side prevent a hit, so
# "class" and "assassin" are safe). A leading '~' matches anywhere in the
# text -- for slurs with no innocent containing words, and for scripts
# written without spaces (CJK, Thai).
